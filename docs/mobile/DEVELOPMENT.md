# Development Environment

---

# Overview

The XynaFaith Mobile project uses a hybrid development workflow.

Development is performed primarily in GitHub Codespaces.

Native platform testing is performed using Android Studio.

iOS builds are performed through GitHub Actions macOS runners.

---

# Development Workflow

GitHub Codespaces

Purpose

- Backend Development
- Frontend Development
- API Development
- Capacitor Configuration
- Documentation

---

Android Studio

Purpose

- Android Emulator
- APK Generation
- Native Debugging
- Camera Testing
- Push Notification Testing

---

GitHub Actions

Purpose

- Automated Builds
- Automated Tests
- Android Releases
- iOS Builds
- TestFlight Deployment
- App Store Releases

# Development Rules

- Use feature branches.
- Keep commits small.
- Document every major change.
- Test before merging.
- Never duplicate frontend code.
