# XynaFaith Mobile

---

## Overview

XynaFaith Mobile is the official native mobile application for the XynaFaith platform.

The mobile application is designed to deliver a production-quality experience for both Android and iOS while maximizing reuse of the existing XynaFaith web platform.

This project is a mobile transformation, not a rewrite.

---

## Goals

- Build one mobile application for Android and iOS.
- Reuse the existing FastAPI backend.
- Reuse the existing UI where appropriate.
- Maintain a single source of truth.
- Deliver a native-quality user experience.
- Integrate seamlessly with XynAssist.
