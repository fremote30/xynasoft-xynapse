# XynaFaith Mobile UI Guidelines

---

# Design Philosophy

The mobile application is an extension of the XynaFaith web platform.

It must preserve the existing visual identity while optimizing the experience for mobile devices.

---

# Colors

Primary

- Blue

Secondary

- White

Accent

- Light Blue

Status

- Success
- Warning
- Error

---

# Typography

Use clean, readable typography.

Prioritize accessibility.

---

# Components

- Cards
- Buttons
- Forms
- Search
- Lists
- Navigation
- Modals

All components must be reusable.

---

# Navigation

Primary navigation uses a bottom navigation bar.

Secondary navigation uses native stack navigation.

---

# Accessibility

- High contrast
- Large touch targets
- Dynamic text support
- Screen reader compatibility

---

# Performance

Avoid unnecessary animations.

Prefer smooth transitions.

Maintain consistent spacing throughout the application.
