# XynaFaith Mobile

## Development Workflow

Edit files only in:

```
ui-faith/
```

Never edit:

```
mobile/www/
```

The mobile frontend is generated automatically.

## Commands

Copy UI:

```bash
npm run copy
```

Sync Android/iOS:

```bash
npm run sync
```

Open Android Studio:

```bash
npm run android
```

Open Xcode:

```bash
npm run ios
```
